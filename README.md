# NOIR · Panel de Licencias (web)

Abre el panel en: **https://noirstudio-web.github.io/noir-panel/**

Esta versión **no contiene la clave** que firma los códigos de activación. La primera vez en cada navegador te pide tu archivo `CLAVE-PRIVADA-NO-COMPARTIR.json` y creas tu usuario y contraseña; la clave queda cifrada solo en ese navegador.

Sin ese archivo nadie puede generar códigos válidos, aunque abra esta página. **Nunca subas el archivo de clave a este repositorio.**
